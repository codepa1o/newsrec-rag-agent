# Hybrid Recommendation Case Study

## 背景

一个新闻推荐系统如果只看点击历史，容易把用户困在单一主题里。加入本地资料库 RAG 之后，系统可以把用户上传的研究笔记、政策摘要和行业说明纳入解释链路。

## 场景

假设用户上传了 AI 治理、推荐透明度和内容审核相关材料。之后他浏览一篇关于算法监管的新闻，系统可以结合这些资料解释：

- 为什么这篇新闻和用户已有兴趣相关。
- 哪些本地资料片段支持这个判断。
- 推荐理由是来自用户画像还是来自知识库语义匹配。

## 关键点

1. 检索阶段先做向量召回，再做关键词补召回。
2. 生成回答时只使用检索到的证据片段。
3. 如果资料支持不强，系统应该优先给出保守结论。

## 推荐测试问题

- 为什么算法监管新闻适合推荐给我？
- 这篇新闻和我的本地资料库有什么关系？
- 如果证据不够，系统应该如何说明？
