# 本地知识库 RAG 导入指南

## 目标

本文件用于测试本地知识库的导入、切分、检索和引用输出。系统在读取这类文档时，应保留文件名、标题路径和 chunk 编号。

## 导入后应观察的行为

1. Markdown 会按标题层级组织语义。
2. 检索问题应该优先命中与“本地知识库”“引用来源”“保守回答”相关的片段。
3. 如果问题与资料无关，系统应返回“没有找到足够依据”，而不是编造结论。

## 推荐测试问题

- 本地知识库问答为什么要保留引用来源？
- Markdown 文档切分时应该保留哪些元数据？
- 资料不足时系统应该怎么回答？

## 预期效果

上传后，回答中最好能出现文件名、chunk 编号或标题路径，并在证据不足时主动降置信度。
